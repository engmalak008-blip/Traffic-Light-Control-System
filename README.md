# Smart Traffic Light Controller | PIC16F877A

## Overview
A traffic light controller system built with the **PIC16F877A microcontroller**.  
It simulates real-world traffic signals with two operating modes:
- **Automatic Mode**: preset timing cycles for each street.
- **Manual Mode**: switch-controlled street selection.

## Features
- LED indicators for Red, Yellow, Green lights.
- 7‑segment displays for countdown timers.
- Switches to toggle between Auto/Manual and select street.
- Proteus simulation for circuit testing.

## Tools & Technologies
- PIC16F877A Microcontroller  
- mikroC PRO for PIC (C programming)  
- Proteus for simulation  
- 7‑Segment displays + BJT drivers  

## How to Run
1. Open the project in Proteus.  
2. Load the compiled `.hex` file into the PIC16F877A.  
3. Run the simulation to test Auto and Manual modes.
